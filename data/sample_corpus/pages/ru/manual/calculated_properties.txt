====== Вычисляемые параметры ======

Вычисляемые параметры - это нехранимые параметры, использующие другие параметры в качестве источника для вычислений. Они хранятся в справочнике {{bslink>Вычисляемые параметры|ShowRepository?20ea8ded-a63b-419e-95a4-1de2955711ea|edit}}.

== == 
**Внимание!** Вместе с системой Business Studio поставляется набор вычисляемых параметров, которые находятся в справочнике "Вычисляемые параметры" в папке "Вычисляемые параметры по умолчанию". 

Если Вы планируете вносить в них изменения или использовать вместо них или вместе с ними свои вычисляемые параметры, см. [[ru/manual/administration/change_and_use_default_data]].
======

Основные возможности вычисляемых параметров:
  * Использование формул для вещественных чисел.
  * Получение новых строковых параметров на основе складывания параметров по указанному шаблону.
  * Создание строковых параметров на основе списков. 
  * Прореживание списков, используемых для вычисления, с помощью наложенных фильтров.
  * Приведение объектного параметра к заданному классу для обращения к его свойствам. 

Для вычисляемого параметра обязательно заполняются {{bslink>Название|ShowOnForm?20ea8ded-a63b-419e-95a4-1de2955711ea;p=9eca45c7-28ab-48a2-b6b5-64bb0bcde9a9,o=Param}} и **Класс создания параметра**, остальные параметры заполняются в зависимости от того, какую задачу должен решать вычисляемый параметр.

Параметры, используемые для вычисления, задаются на вкладке {{bslink>Используемые параметры|ShowOnForm?20ea8ded-a63b-419e-95a4-1de2955711ea;p=d26572df-0fdb-46a1-bcf9-f50e2e3fded5,o=Param}}, детальные настройки делаются в окне свойств строк этого списка.

С примерами настройки параметров для различных задач можно ознакомиться в справочнике **Вычисляемые параметры** в папке "Вычисляемые параметры по умолчанию".

Для вычислимых параметров поддерживаются настройка доп. опций на вкладке {{bslink>Допопции|ShowOnForm?20ea8ded-a63b-419e-95a4-1de2955711ea;p=d02ea9f6-9ef0-4172-91d5-f36aa88a7ada,o=Param}}  (подробнее о доп. опциях параметров см. [[ru/technical_manual/editor_param_class/edit_metadata#настройки_параметра_класса|Настройки параметра класса]]) и настройка видимости параметров на вкладке {{bslink>Группы параметров|ShowOnForm?20ea8ded-a63b-419e-95a4-1de2955711ea;p=d7f37700-4a56-4621-92aa-b9558919e821,o=Param}}.
