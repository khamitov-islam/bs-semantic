====== Поиск объекта по идентификатору (ID) ======

У объектов в базе данных есть идентификатор объекта - параметр ID. Его значение в пределах базы данных является уникальным.
Зная ID объекта и его класс можно найти этот объект в базе данных. 

Это может потребоваться для поиска объекта в случаях, если про него нет другой информации, кроме класса и ID. Такая ситуация может возникнуть, например, при конвертации базы данных, когда после ее окончания в логе пользователю будет выдано сообщение с этими данными и потребуется найти в базе соответствующий объект.

Вызов **Окна поиска по ID** осуществляется по кнопке **Открыть объект по ID** из **Меню администратора** ({{bslink>Меню Администратора → Администрирование → Открыть объект по ID|ShowRibbonPageOrItem?mi_Adm;miGetObjectByID:Item}}).

Задав в этом окне значения в параметрах "Класс объекта" (выбором по кнопке "..."; в окне выбора доступен поиск по названию класса, вызываемый сочетанием клавиш "Ctrl+F") и "Идентификатор объекта", можно открыть свойства самого искомого объекта по кнопке "Свойства объекта" и свойства его владельца по кнопке "Свйоства владельца" соответственно.

Под владельцами в данном случае понимаются:
  * Для вспомогательных справочников импорта - соответствующие пакеты импорта.
  * Для вспомогательных справочников фильтров - соответствующие фильтры.
  * Для привязок отчетов - соответствующие отчеты.
  * Для остальных справочников из Элементов списков - объекты из параметра "Владелец" этих справочников.
  * Для остальных классов из "Классы" - владельцы отсутствуют.
