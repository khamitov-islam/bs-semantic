====== Системные требования ======

Компьютеры могут выполнять различные роли при работе с Business Studio, при этом каждый компьютер может выполнять одну или несколько ролей одновременно. 
Полный перечень ролей, их описание и системные требования к компьютерам, выполняющим их, приведены ниже.

===== Роли компьютеров при работе с Business Studio =====

  * **Рабочая станция** – используется для установки клиентской части Business Studio или Business Studio Cockpit, непосредственно на нём будет вестись работа в программе Business Studio.
  * **Сервер баз данных** – используется для размещения баз данных. 
  * **Сервер лицензий** – используется для выделения пользователям подключений конкурентной лицензии и обеспечения совместной работы пользователей в базе данных. Каждая база данных настроена на использование определенного сервера лицензий. 
  * **Основной сервер Business Studio Portal** – выступает в качестве основного сервера, на котором будет сформирован и запущен Business Studio Portal (см. [[ru/manual/portal]]). 
  * **Вспомогательный сервер Business Studio Portal** – выступает в качестве сервера-помощника, предназначенного в основном для формирования отчётов для Business Studio Portal (см. [[ru/manual/portal]] и [[ru/manual/portal/distributed]]). 
  * **Рабочая станция для массового формирования отчётов, HTML-публикации** - используется для выполнения указанных в названии сценариев: пакетного формирования отчетов (см. [[ru/manual/report/packet_report]]) и HTML-публикации (см. [[ru/manual/html]]).
  * **Сервер для развертывания сформированной HTML-публикации** - используется для развертывания ранее сформированной на этом или другом компьютере HTML-публикации (см. [[ru/manual/html/work_description/run_html]]).
  * **Рабочая станция для просмотра HTML-публикации, работы с Business Studio Portal и системой Справки** - используется для просмотра HTML-страниц, создаваемых Business Studio (см. [[ru/manual/html|HTML-публикация]], [[ru/manual/portal|Business Studio Portal]]) и имеющих отношение к Business Studio (справка), не требующее установки самой программы.
  * **Сервер обслуживания клиентов** (внешняя служба ГК "Современные технологии управления") – используется для предоставления решений по ошибкам, отправки уведомлений, ссылок на скачивание обновлений Business Studio, регистрации новых пользователей.
  * **Сервер контроля лицензий** (внешняя служба ГК "Современные технологии управления") – предназначен для контроля за использованием онлайн-лицензий. При обнаружении одновременного использования онлайн-лицензии Группа компаний "Современные технологии управления" вправе приостановить её действие.

Приведены только версии ПО с активной поддержкой от Microsoft.

===== Рабочая станция, сервер баз данных для 1-5 подключений, сервер лицензий =====
== ==
**Внимание!** При расчете требований к аппаратному обеспечению для роли сервера баз данных каждый служебный процесс Business Studio Portal (см. [[https://www.businessstudio.ru/help/docs/current/doku.php/ru/manual/portal/setting/create_new_portal|Создание нового портала]]) требуется учитывать как отдельное подключение.
==== ====
**Аппаратное обеспечение**

Приведенные ниже требования к аппаратному обеспечению действительны в том числе для любых комбинаций указанных ролей. При использовании в комбинации с другими ролями для получения общих системных требований нужно объединить аппаратные требования ролей.

  * Объем оперативной памяти: 4 Гб.
  * Процессор: Intel Core i3 (2 ядра) и выше.
  * Дисковая память: 5 Гб свободного места на диске.
  * Сетевое подключение: 100 Мбит/с.
  * Разрешение экрана: 1920*1080 или более высокое.

**Программное обеспечение**

  * Microsoft Windows 10, Microsoft Windows 11, Microsoft Windows Server 2016, Microsoft Windows Server 2019, Microsoft Windows Server 2022 (32 бит/64 бит).
  * Microsoft .NET Framework 4.8 (при необходимости устанавливается инсталлятором).
  * Microsoft Visual C++ 2015-2019 Redistributable (при необходимости устанавливается инсталлятором).
Для роли "Сервер баз данных":
  * Одна из следующих СУБД:
    * Microsoft SQL Server 2017/2019/2022((При необходимости Microsoft SQL Server  2017 Express Edition устанавливается  инсталлятором.));
    * PostgreSQL начиная с версии 14.6 и совместимые, включая Postgres Pro.

Для роли "Рабочая станция"
  * Для работы с диаграммами: \\ В версии Business Studio 6.0 до выхода версии 7.0 будет разница в функционале в зависимости от используемого редактора для диаграмм справочника "Деятельность" (пользователю будет предложен выбор, какой редактор использовать: MS Visio или встроенный). В остальных справочниках будет использоваться только встроенный редактор диаграмм. \\ Подробнее о различиях в функционале см. [[https://www.businessstudio.ru/buy/editors/|на сайте businessstudio.ru]]. \\ В случае выбора для справочника "Деятельность" варианта "MS Visio" необходимо наличие Microsoft Visio Standard/Professional/Premium 2013/2016/2019/2021.
  * Для формирования отчетов, HTML-публикации, отчетов Business Studio Portal:
    * Требования по наличию MS Word и MS Excel:  
      * Для отчетов с шаблонами формата MS Excel, а также отчетов, использующих макросы VBA: Microsoft Word 2013/2016/2019/2021/2024 (кроме редакции Starter), Microsoft Excel 2013/2016/2019/2021/2024 (кроме редакции Starter).​​​​​
      * Для отчетов с шаблонами формата MS Word без макросов VBA:​​ нет требований по наличию внешнего ПО. 
    * Требования по наличию MS Visio:
      * Для баз, в которых для работы со справочником Деятельность выбран редактор MS Visio: Microsoft Visio Standard/Professional/Premium 2013/2016/2019/2021.
      * Для баз, в которых для работы со справочником Деятельность выбран встроенный редактор (не выбран редактор MS Visio): нет требований по наличию внешнего ПО.

Также см. [[ru/manual/install/requirements#дополнительная_информация_по_требуемому_программному_обеспечению|Дополнительная информация по требуемому программному обеспечению]].

**Сетевая инфраструктура**
  * Доступ к сети Интернет: Да, для доступа: 
    - К Серверу обслуживания клиентов
    - К Серверу контроля лицензий, если компьютер выполняет роль "Сервер лицензий" и для активации программы используется онлайн-лицензия((Онлайн-лицензия используется для активации временных лицензий и активации на виртуальных машинах. В случае, если обеспечить доступ к сети Интернет проблематично, при использовании постоянной лицензии можно выбрать для активации не виртуальную, а физическую машину, тогда доступ к сети Интернет не потребуется.)) (подробнее см. [[ru/manual/install/activation/online_activation]]).

===== Основной сервер Business Studio Portal (до 1000 пользователей) =====

**Аппаратное обеспечение**

При использовании в комбинации с другими ролями для получения общих системных требований нужно объединить аппаратные требования ролей.

  * Объем оперативной памяти: 4 Гб + 2 Гб на каждый служебный процесс (расчет количества служебных процессов и серверов приведен в статье [[ru/manual/portal/optimization_of_portal_generation_time/optimize_time/distributed_generation_of_portal_reports]]).
  * Процессор: Intel Core i3 и выше, 2 ядра + 1 ядро на каждый служебный процесс (см. [[ru/manual/portal/setting/create_new_portal]]).
  * Дисковая память: 1 Гб постоянно свободного места, а также место под каждый формируемый портал на системном диске, где установлена OC Windows (рекомендуется резервировать на один портал места в 3 раза больше, чем занимает база данных Business Studio, по которой он формируется).
  * Сетевое подключение: 1 Гбит/с.

**Программное обеспечение**

  * Microsoft Windows Server 2016, Microsoft Windows Server 2019, Microsoft Windows Server 2022 (64 бит).
  * Microsoft .NET Framework 4.8 (при необходимости устанавливается инсталлятором).
  * Microsoft Visual C++ 2015-2019 Redistributable (при необходимости устанавливается инсталлятором).
  * Для формирования отчетов Business Studio Portal:
    * Требования по наличию MS Word и MS Excel:

      * Для отчетов с шаблонами формата MS Word без макросов VBA:​​ нет требований по наличию внешнего ПО.

      * Для баз, в которых для работы со справочником Деятельность выбран встроенный редактор (не выбран редактор MS Visio): нет требований по наличию внешнего ПО.

Рекомендуется использовать 64-битные версии приложений MS Office (при необходимости) и Business Studio.

===== Дополнительная информация по требуемому программному обеспечению =====

==== Microsoft SQL Server ====

В случае одновременного подключения к серверу Business Studio более 10 пользователей, рекомендуется использовать полнофункциональную версию Microsoft SQL Server.

Версия Microsoft SQL Server Express Edition, которая устанавливается инсталлятором, имеет следующие ограничения:
  * Используемое число процессоров/ядер - меньшее из 1 процессора или 4 ядер.
  * Используемый объем оперативной памяти - не более 1 Гб.
  * Размер базы данных - не более 10 Гб.

==== Комбинация Microsoft Word, Microsoft Excel и Microsoft Visio ====

В пределах каждого сервера/рабочей станции рекомендуется использовать набор приложений Microsoft Word, Microsoft Excel и Microsoft Visio одной и той же версии (например, 2013). В силу особенностей MS Office установка приложений, не принадлежащих одной версии, может вызывать ошибки при работе с диаграммами и формировании отчетов.

==== Microsoft Visio ====

Рекомендуется на всех рабочих станциях использовать Microsoft Visio одной и той же версии и локализации. Диаграммы, созданные с использованием разных языковых пакетов или более поздних версий, в других версиях могут обрабатываться некорректно.

В частности диаграммы, созданные с использованием Microsoft Visio 2013, не могут открываться и обрабатываться с иcпользованием  Microsoft Visio более ранних версий((В Business Studio 4.2.6400 добавлена поддержка опции MS Visio "Сохранять файлы в следующем формате", благодаря чему при установке у всех работающих с диаграммами пользователей в MS Visio одинаковых значений этой опции теперь можно работать с диаграммами, используя разные версии MS Visio.)).

Бесплатную 30-дневную версию Microsoft Visio можно скачать по следующей ссылке: https://signup.microsoft.com/Signup?OfferId=0F5B471A-08EF-4e69-ABB0-BB4DA43F0344&DL=VISIOCLIENT&culture=ru-RU&country=RU&ali=1

Для установки данной версии Visio может потребоваться, чтобы и другие установленные программы пакета MS Office имели тип лицензии Office 365.
